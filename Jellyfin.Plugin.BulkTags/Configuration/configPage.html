Bulk Tags Plugin Configuration

This plugin allows you to add or remove tags from multiple items at once in your Jellyfin library.

When enabled, the plugin will log detailed information about bulk tagging operations.
Maximum number of items to process in a single batch operation (1-1000).

API Endpoints

The plugin provides the following API endpoints for bulk operations:

  • POST /BulkTags/AddTags - Add tags to multiple items
  • POST /BulkTags/RemoveTags - Remove tags from multiple items

Request body format:

{
  "ItemIds": ["item-id-1", "item-id-2"],
  "Tags": ["tag1", "tag2"]
}
